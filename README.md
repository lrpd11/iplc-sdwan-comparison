## IPLC 和 SD-WAN 的本质区别是什么？

一句话概括：IPLC 是“独占车道”，SD-WAN 是“会挑路的导航”。前者的带宽从物理上划给你专用，后者的价值在于把多条链路调度好。

|  | IPLC 专线 | SD-WAN |
| --- | --- | --- |
| 技术原理 | 基于 SDH/PDH（TDM）的物理隔离点对点电路，数据不经过公网 | 软件定义的 overlay，聚合专线、宽带、4G/5G，按应用智能选路 |
| 性能 | 带宽独享，抖动趋近零，丢包趋近零 | 质量取决于底层链路，国际网关拥塞时软件帮不上忙 |
| 可用性（厂商公开典型值） | 最高可达 99.99% | 约 99.95%，靠多路径冗余和自动切换 |
| 扩展性 | 带宽固定，扩容要动物理线路，常见 2–4 周；新增站点要新开电路 | 分钟级弹性调整，新站点接入快 |
| 成本 | 最贵，费用随带宽线性增长，线路租金约占年成本 75%–85% | 最低，用廉价本地宽带分流；另需设备和软件许可费用 |
| 适合谁 | 金融交易、两地数据中心同步、核心系统容灾 | 多站点办公、SaaS、跨国视频会议 |

顺带说一句隔离等级：公网共享网关最弱，CN2 是运营商骨干内的优先转发，IEPL 用以太网二层技术做逻辑隔离，IPLC 通过光传输网络做到物理隔离。隔离越彻底越稳，也越贵。

## 性能差距有多大？看具体数字

日常收邮件、刷网页，两条路你基本感知不出差别；差距全部集中在实时业务上。

SD-WAN 的加密封装本身要吃掉约 10% 的带宽，再叠加 5–20ms 延迟。IPLC 没有这些开销：固定带宽、固定延迟、几乎零抖动。有服务商公开的实测参考：IEPL 广州到香港 1–2ms，上海到日本 25–28ms，上海到美国 124–134ms。

不过 SD-WAN 也有自己的强项：绕路。集中控制平台实时监控几十项网络指标，自动绕开拥塞节点，有厂商给出的案例是把跨洲视频会议延迟从 500ms 压到 150ms 以内。但有个绕不开的物理事实——国际出口真堵起来，任何 SD-WAN 都无法改善底层质量，它能做的只是提前把流量挪到没堵的那条路上。

## 成本账：100M 跨境带宽一年花多少钱

纯专线最贵，混合架构最划算，这个结论有具体数字支撑。

以服务商公开的案例价为例：一条 100M 国际专线年费大约 15 万元；同样的需求，SD-WAN 混合链路可以控制在 8 万元以内。对 10 个以上分支点的中型企业，有测算显示 SD-WAN 方案三年 TCO 能比传统方案低 32%–48%。

更省的玩法是混合。混合方案的总体成本通常只有纯专线的 30%–50%，却能覆盖 90% 以上的业务需求。逻辑很简单：一家 100 人的办公室总带宽可能要 200Mbps，但真正需要专线保障的实时音视频、ERP、数据库同步，往往只有 20–30Mbps，剩下 170Mbps 走本地宽带绰绰有余。

扩容的成本差异同样值得算：IPLC 加带宽要等 2–4 周的物理施工，费用基本随带宽线性上涨；IEPL 可以按 2Mbps 的粒度远程调整；SD-WAN 则是分钟级弹性伸缩。

## 在中国大陆跨境组网，合规是第一道门槛

先说结论：在中国大陆做跨境组网，合规直接决定方案能不能用，而不只是加分项。

传统基于 IP 的 VPN 在大陆属于被明确禁止的类型，只有经政府批准的服务才合法；基于 MPLS 或 SD-WAN 技术实现、通过授权电信运营商搭建的企业内部跨境连接，则是被允许的路径。没人管的时代已经结束了：未获批的 VPN 服务会被封锁和限速，敏感时期和重大节点前后尤其不稳。执法历史上更多针对服务商，但使用方的企业同样有处罚风险。

落到方案设计上，大陆的 SD-WAN 通常是“双网架构”：境内一张网、境外一张网，中间经香港或新加坡的持牌专线桥接；境内站点通过本地宽带以 IPsec 隧道接入。这也是它成本能压下来的原因——边缘用便宜的本地宽带，而不是每个站点都拉昂贵的电路。MPLS 这条老路则通过中国电信、中国联通、中国移动这样的持牌运营商提供。

选购时的第一个动作就是确认服务商资质。这一步不过关，后面价格谈得再好都没有意义。

## IPLC、IEPL 与“假专线”：下单前分清

市场上叫“专线”的产品很多，底层可能是完全不同的东西，下单前要分清三件事。

IPLC 和 IEPL 是两代技术。IPLC 基于 SDH/PDH 的时分复用，把光纤带宽切成固定时隙出租，带宽绝对保证，但调整容量要做工程级改动。IEPL 建立在 MSTP 平台上，直接承载以太网帧，两端用标准网口接交换机就能用，带宽能按 2Mbps 的粒度远程调整，单位带宽的成本也更友好。对新组网来说，除非有特殊要求，IEPL 通常是更现代的选择。

还有一个避坑点值得单独说：真正的 IPLC 投入大、开通周期长，通常只有国企、银行和大型跨国公司在用。市面上不少标着"IPLC"的产品，实际是部分租用线路或内网中转。报价明显低于市场水平、又说不清物理路由和隔离方式的，多问几句再掏钱。

## 混合架构怎么搭：分三步走

混合架构的核心原则是用专线保证关键业务，用 SD-WAN 优化整体效率。

1. 先上一条 IPLC/IEPL，把最关键的业务锚定在 SLA 上，这是整个网络的地基。
2. 流量涨了之后叠加 SD-WAN，把非关键流量卸载到本地宽带，减轻专线压力。
3. 根据实际流量数据调整专线带宽、SD-WAN 策略和链路组合，需要的话再加 4G/5G 做备份。

流量分层可以直接照抄：实时音视频、ERP/CRM/财务系统、数据库同步备份、金融交易走专线；Office 365 这类 SaaS、远程桌面和 VDI、文件协作走 SD-WAN 智能选路；普通网页浏览、软件更新下载走普通宽带。专线故障时，Tier 1 流量可以临时降级到 SD-WAN 加密隧道，质量会打折，但业务不中断。

几个直接的决策规则：每年新增站点超过 20 个的，选 SD-WAN；金融、政务这类对合规要求极高的，IPLC 优先；重度依赖多云的，SD-WAN 原生的云直连优势明显。

## 常见问题

### SD-WAN 能完全替代专线吗？

不能。SD-WAN 本身没有传输能力，质量上限由底层链路决定，国际网关拥塞时段它无能为力。它的正确用法是把多数流量从专线上卸下来，让专线带宽花在刀刃上。

### IPLC 和 SD-WAN 能一起用吗？

能，而且是主流组合。常见做法是 SD-WAN 承载普通办公流量，IPLC 在底下承载单一关键流。汽车行业有过德国总部到上海研发中心走 IPLC、东南亚 30 个经销商走 SD-WAN 的组合案例。

### 市面上便宜的"IPLC"是真的吗？

多数要打问号。真 IPLC 通常是国企、银行、跨国公司的配置，报价异常低的产品很多是部分租用线路或内网中转。判断方法：问清是否物理隔离、路由怎么走、开通周期多长，答不上来的基本可以排除。

### 从下单到开通要多久？

专线以周计，运营商、城市、楼宇不同差别很大；IPLC 扩容常见 2–4 周。整个跨境组网项目里，线路开通几乎总是最长的环节，排项目计划时把这段时间留足。

## 下单前的最后建议

按情况对号入座：只有一条固定的点对点大流量管道（两地机房同步、交易链路），直接上 IPLC 或 IEPL；站点多、变化快、预算紧，SD-WAN 起步；既要稳又要省，混合架构，专线带宽从 20–30Mbps 起按关键流量定。

下单前确认两件事：一是服务商的跨境业务资质是否齐全，这在大陆不是走形式；二是报价是否包含两端本地接入和设备，别等合同签完才发现漏项。
